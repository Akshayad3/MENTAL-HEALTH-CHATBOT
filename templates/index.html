        Understanding the Evaluation

        These metrics show how accurately MindFlow identifies the user's conversation intent and emotional patterns from text.

        How to read a confusion matrix:
        • Rows represent the actual class.
        • Columns represent the predicted class.
        • Values on the diagonal represent correct predictions.
        • Values outside the diagonal represent cases where the model confused one class with another.
